## Run locally

No installation needed. Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/charantejakatari/charantejakatari.github.io.git
cd charantejakatari.github.io
open index.html   # macOS; on Windows use: start index.html
```

## Deployment

The site is served by GitHub Pages from the root of the default branch. Pushing changes to `index.html` or `og-image.png` updates the live site within a minute or two.
